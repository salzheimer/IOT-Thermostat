# MicroPython Thermostat Project Requirements

# MicroPython Version
# Tested with MicroPython v1.22.0+ on Raspberry Pi Pico W
# Minimum required: MicroPython v1.20.0 (for SSL/TLS support)

## Built-in MicroPython Libraries (no installation required)
# - dht (DHT11/DHT22 sensor driver)
# - machine (Pin, SoftI2C for hardware control)
# - network (WiFi connectivity)
# - ntptime (NTP time synchronization)
# - ssl (SSL/TLS support for secure connections)
# - json (JSON encoding/decoding)
# - time/utime (Time functions)
# - os (File system operations)

## Network Communication Libraries

# HTTP Client (for SAS Token authentication)
# - urequests (MicroPython HTTP library for REST API calls to Azure IoT Hub)

# MQTT Client (for X.509 Certificate authentication)
# - umqtt.simple (MicroPython MQTT client library)
# Installation: Copy to lib/ directory or install via upip:
#   >>> import upip
#   >>> upip.install('micropython-umqtt.simple')

## Custom Drivers (included in this project)
# - drivers/pico_i2c_lcd.py (I2C LCD driver for HD44780-compatible displays)
# - drivers/lcd_api.py (LCD API abstraction layer)

## Project Modules
# - src/thermostat.py (Temperature/humidity sensor reading)
# - src/display.py (LCD display management)
# - src/data_send.py (Azure IoT Hub communication - dual authentication support)
# - utils/config_reader.py (Configuration file parser)
# - utils/wifi_connect.py (WiFi connection management)

## Azure IoT Hub Requirements

# For SAS Token Authentication:
# - Valid Azure IoT Hub instance
# - Device registered with SAS token
# - Network connectivity

# For X.509 Certificate Authentication:
# - Valid Azure IoT Hub instance
# - Device registered with X.509 thumbprint
# - Device certificate (.crt) and private key (.key) files
# - Certificates in DER or PEM format (DER recommended for MicroPython)
# - Network connectivity with TLS/SSL support

## Development Dependencies (for testing on Python 3)
# Uncomment the following for local development/testing:
# pytest>=7.0.0
# pytest-cov>=4.0.0
# ruff>=0.1.0  # Linter and formatter
# mypy>=1.0.0  # Type checker

## Installation Notes

# MicroPython libraries cannot be installed via pip on your development machine.
# These must be copied directly to the Pico device or installed via upip on the device.

# Directory structure on Pico:
# /
# ├── main.py
# ├── config.txt
# ├── src/
# ├── drivers/
# ├── utils/
# ├── certs/ (if using X.509 authentication)
# └── lib/ (for external libraries like umqtt)

## External Library Installation Options

# Option 1: Using upip on the device (requires WiFi connection)
# >>> import upip
# >>> upip.install('micropython-umqtt.simple')

# Option 2: Manual installation
# Download from https://github.com/micropython/micropython-lib
# Copy to lib/ directory on the Pico
